# Contributing

1. Fork and clone the repository.
2. Create a virtual environment and install the dev extras:

   ```bash
   pip install -e ".[dev]"
   ```

3. Create a topic branch, make your change and add tests.
4. Run `ruff check .` and `pytest` before opening a pull request.
5. Use short, imperative commit messages (for example `Add SELFIES encoder`).

Please do not force push to shared branches.
